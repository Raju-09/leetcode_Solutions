## Problem Description

You are given an array of non-overlapping intervals `intervals` sorted by `start_i`. Insert `newInterval` into `intervals` such that intervals is still sorted and non-overlapping.

<strong class="example">Example:</strong>

```
**Input:** intervals = [[1,3],[6,9]], newInterval = [2,5]
**Output:** [[1,5],[6,9]]
```

**Constraints:**

- `0 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= start_i <= end_i <= 10^5`
