## Problem Description

An obstacle and space are marked as `1` and `0` respectively in `obstacleGrid`. Return the number of possible unique paths that the robot can take to reach the bottom-right corner.

<strong class="example">Example:</strong>

```
**Input:** obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
**Output:** 2
```

**Constraints:**

- `m == obstacleGrid.length`
- `n == obstacleGrid[i].length`
- `1 <= m, n <= 100`
