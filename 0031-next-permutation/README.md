## Problem Description

A **permutation** of an array of integers is an arrangement of its members into a sequence or linear order. Find the next lexicographical permutation.

<strong class="example">Example:</strong>

```
**Input:** nums = [1,2,3]
**Output:** [1,3,2]
```

**Constraints:**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`
