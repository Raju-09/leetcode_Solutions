## Problem Description

There is a robot on an `m x n` grid. The robot can only move either down or right at any point in time. How many possible unique paths are there to reach the bottom-right corner?

<strong class="example">Example:</strong>

```
**Input:** m = 3, n = 7
**Output:** 28
```

**Constraints:**

- `1 <= m, n <= 100`
